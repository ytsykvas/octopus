# Компонент UI

Стиль — **необруталізм**: чорні бордери, жорсткі зміщені тіні без розмиття,
насичені акценти, підкреслено «фізична» взаємодія (§10 docs/PROJECT.md).

Токени живуть у `src/renderer/src/styles.css`. **Ніколи не вписуй кольори
чи тіні напряму** — тільки через токени, інакше темна тема зламається.

## Масштаб елементів

Бордер, радіус і тінь ростуть разом з елементом — це основа впізнаваності стилю:

| Елемент | Бордер | Радіус            | Тінь                 | Зсув на hover |
| ------- | ------ | ----------------- | -------------------- | ------------- |
| Бейдж   | 2px    | `--radius-badge`  | `--shadow-brutal-sm` | `-1px, -1px`  |
| Кнопка  | 3px    | `--radius-brutal` | `--shadow-brutal`    | `-2px, -2px`  |
| Картка  | 3px    | `--radius-brutal` | `--shadow-brutal`    | `-3px, -3px`  |

`:active` завжди скидає зсув у `translate(0,0)` і стискає тінь до
`--shadow-brutal-sm` — це дає відчуття натискання.

## Готові класи

Перш ніж писати стилі, перевір `styles.css` — базові патерни вже є:

- `.brutal-surface` — панель: фон, бордер 3px, радіус, тінь;
- `.brutal-interactive` — переходи + hover/active зі зсувом;
- `.brutal-label` — `uppercase` + `font-weight: 900` + letter-spacing;
- `.titlebar-drag` — зона перетягування вікна під тайтлбаром.

## Кольори — тільки через токени

```tsx
// Добре
<div className="bg-surface text-ink border-outline">

// Погано — темна тема зламається
<div className="bg-[#d6e0df] text-black border-black">
```

Доступні: `canvas`, `surface`, `muted`, `outline`, `ink`, `ink-soft`,
`success`, `danger`, `warning`, `info`, `primary`, `secondary`.

**Текст на акценті** бери з парного токена `on-*`, не з `text-black`:

```tsx
<span className="bg-success text-on-success">idle</span>
```

Причина: у світлій темі на `danger` текст білий, а в темній — темний.
Токен `on-danger` враховує це сам.

## Типографіка — головне обмеження

`uppercase` + `font-weight: 900` — **тільки** для кнопок, бейджів, лейблів
і заголовків панелей.

Вміст чату з агентом, дифи й логи інструментів ідуть **звичайним регістром**,
нормальною вагою; код — моноширинним (`font-mono`). Джерело дизайну — CRUD
з короткими написами, а в нас щільний текст, і суцільний uppercase зробить
його нечитабельним (§10.6).

## Темна тема

Нічого робити не треба, якщо використовуєш токени: `.dark` на `<html>`
перемикає всі значення разом. Клас ставить `App.tsx` за подією з main-процесу.

Перевіряй обидві теми — на темному фоні чорні тіні зникають, і саме тому
`--outline` там світлий (інверсія контуру, §10.7).

## Куди не класти логіку

Компонент рендерить і викликає `window.maestro.*`. Робота з git, файлами,
процесами живе в `src/core/` — renderer вважається замінним, бо лейаут ще
не обрано (§17), і логіка в ньому загубиться при переписуванні.
